# SLC 制作研修｜カンプどおりに作る、最初のワンサイト

HTML/CSSコーディングの制作研修で使う手順書です。公開中サイトのデータ一式をFTPでダウンロードするところから、カンプどおりにトップページをリニューアルするまでを、STEP 0〜9 と最終チェックで進めます。WordPressやPHPは使いません。

- **手順書**：[guide.html](guide.html)（単一HTML。ブラウザで開くだけで読めます）
- 進捗はブラウザに保存されます。各STEPの「クリア」を押すとレベルが上がり、スラ先輩の装備が増えます。

## このリポジトリに入っていないもの

演習に必要な配布物のうち、以下は容量とライセンスの都合で含めていません。教育担当から直接受け取ってください。

- `comp/` … デザインカンプ（PC 1440×18,025px／SP 375×24,620px）
- `material/photos/`、`material/logo.svg` … 演習で使う写真23枚とロゴ

サイトデータ一式は配布物ではなく、研修の中でFTPを使って本番サーバーから各自ダウンロードします（接続情報は教育担当から）。
